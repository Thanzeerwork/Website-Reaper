# Web Clone Architect (Claude Code Skill)

Follow the 6-Phase User-Driven Interactive Protocol to convert cloned websites or raw HTML into clean, componentized frameworks:
1. Phase 1: Ingestion & Inspection (Ask which sections to convert).
2. Phase 2: Target Framework Selection (Next.js 15, Vite React TS, Nuxt 3, Svelte 5, Astro 5).
3. Phase 3: Component Granularity (Atomic primitives + Sections vs Section-only files).
4. Phase 4: Asset, SVG & 3D Strategy (Lucide mapping, React Three Fiber, Spline).
5. Phase 5: Animation & State Protocol (Framer Motion scroll reveals, mobile drawer, accordions, theme toggle).
6. Phase 6: Incremental Generation & Verification (Module-by-module checkpointing).
